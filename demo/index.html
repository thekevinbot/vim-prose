vim-prose

Vim keybindings for Tiptap / ProseMirror

Normal

Mode Switching

  • i insert before cursor
  • a insert after cursor
  • o open line below
  • Esc back to normal

Motions

  • hjkl navigate
  • wb word forward / back
  • 0$ line start / end
  • ggG doc start / end

Operators

  • dw delete word
  • dd delete line
  • yy yank line
  • p paste

Visual

  • v visual mode
  • V visual-line mode
  • u undo
  • Ctrl+r redo
